DATOS DE EJEMPLO
Cómo se conecta (IoT real): el nodo montado en la maquinaria mide el suelo y el ESP32 escribe cada lectura en la base Supabase (http.POST a .../rest/v1/lecturas). Esta página lee de esa misma base (fetch a la misma URL y tabla). El sensor escribe, la página lee: se conectan a través de la base.
Nota: datos de ejemplo para la demostración. Cuando la página se abre desde un servidor (no como archivo), se conecta en vivo a Supabase. Rangos de cultivos orientativos (a ajustar con datos del INTA).
